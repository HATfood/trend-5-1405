# داشبورد ۵ روند برتر ۱۴۰۵

نسخه مستقل و استاتیک داشبورد هستی آرین تأمین، مناسب اجرای مستقیم روی کامپیوتر و انتشار در GitHub Pages.

رمز ورود پیش‌فرض:

    nsa123

صفحه ورود به‌صورت سمت کاربر اجرا می‌شود. این روش برای جلوگیری از مشاهده عادی مناسب است، اما جایگزین احراز هویت واقعی سمت سرور نیست.

## اجرای محلی

ساده‌ترین روش این است که فایل index.html را با مرورگر باز کنید.

برای اجرای سایت از طریق یک وب‌سرور محلی، داخل همین پوشه دستور زیر را اجرا کنید:

    python -m http.server 8000

سپس آدرس زیر را باز کنید:

    http://localhost:8000

## انتشار در GitHub Pages

1. یک Repository جدید در GitHub بسازید.
2. تمام فایل‌های همین پوشه را در شاخه اصلی Repository آپلود کنید.
3. به Settings و سپس Pages بروید.
4. در بخش Build and deployment گزینه Deploy from a branch را انتخاب کنید.
5. شاخه main و پوشه root را انتخاب و ذخیره کنید.

پس از چند دقیقه، لینک عمومی سایت در همان صفحه نمایش داده می‌شود.

## ساختار فایل‌ها

- index.html: ساختار صفحه
- styles.css: طراحی واکنش‌گرا
- script.js: داده‌ها، نمودارها و تعاملات
- .nojekyll: جلوگیری از پردازش اضافی GitHub Pages

برای تغییر اعداد، آرایه categories در ابتدای فایل script.js را ویرایش کنید.

برای تغییر رمز، مقدار passwordHash در فایل script.js را با هش SHA-256 رمز جدید جایگزین کنید.
